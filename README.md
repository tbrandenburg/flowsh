# flowsh

**The jq of Workflows** - Simple YAML workflow to shell script compiler

flowsh converts YAML workflow definitions into clean, readable shell scripts. Think of it as `jq` for workflows - a focused, unix-philosophy tool that does one thing extremely well.

## What flowsh does

```bash
# Compile workflow to shell script
flowsh compile workflow.yaml > script.sh

# Validate workflow syntax
flowsh validate workflow.yaml

# Execute the generated script
bash script.sh
```

## Why flowsh?

- **Simple** - Two commands: `compile` and `validate`
- **Clean Output** - Generates readable shell scripts under 100 lines
- **Zero Dependencies** - Generated scripts run anywhere with bash/zsh
- **Unix Philosophy** - Does one thing well, plays nicely with other tools
- **jq-like UX** - Familiar command-line interface for developers

## 🆕 What's New - Phase 2A

flowsh now supports **enhanced control flow** with loops and iterations, making it practical for real-world automation:

- **Loop Nodes** - Conditional repetition with safety limits (prevents infinite loops)
- **Iteration Nodes** - Array processing with JSON and newline-separated input support
- **Rich Utility Framework** - Enhanced logging, debugging, and error handling
- **Variable Context** - Loop and iteration variables (`loop_index`, `iteration_item`, etc.)

See `examples/counting-loop.yaml` and `examples/file-processing-iteration.yaml` for working examples.

## Example

### Input: workflow.yaml

```yaml
workflow:
  name: 'Hello World'
  description: 'Simple greeting workflow'

graph:
  nodes:
    - id: 'start'
      type: 'start'
      data:
        title: 'Start'

    - id: 'greet'
      type: 'code'
      data:
        title: 'Generate Greeting'
        command: 'echo "Hello, World!"'

    - id: 'end'
      type: 'end'
      data:
        title: 'Complete'

  edges:
    - source: 'start'
      target: 'greet'
    - source: 'greet'
      target: 'end'
```

### Output: Generated Shell Script

```bash
#!/bin/bash
set -euo pipefail

# Hello World - Generated by flowsh
# Simple workflow execution script

echo "Starting workflow: Hello World"

# Workflow Execution

# Node: greet
echo "Hello, World!"

echo "Workflow completed successfully"
exit 0
```

## Commands

### compile

Convert YAML workflow to shell script (outputs to stdout):

```bash
flowsh compile workflow.yaml > script.sh
flowsh compile workflow.yaml | bash  # Direct execution
flowsh compile workflow.yaml --verbose  # Show detailed progress
```

**Options:**

- `--verbose`, `-v` - Show detailed progress and performance information

### validate

Check workflow YAML for syntax errors:

```bash
flowsh validate workflow.yaml
# ✅ workflow.yaml is valid (3 nodes, 2 edges)
```

## Supported Node Types

flowsh supports a focused set of node types optimized for shell script generation:

**Core Workflow Nodes:**

- **start/end** - Workflow boundaries and control flow
- **answer** - Workflow completion with output messages
- **code** - Shell command execution and script integration
- **agent** - CLI tool orchestration (opencode, git, npm, etc.)
- **llm** - AI model integration via API calls
- **variable-assignment** - Dynamic variable management and templating
- **if-else** - Conditional workflow branching and logic

**Phase 2A - Enhanced Control Flow:**

- **loop** - Conditional repetition with break conditions and safety limits
- **iteration** - Array/list processing with sequential or parallel execution

## Design Philosophy

flowsh follows the Unix philosophy:

1. **Do one thing well** - Convert workflows to shell scripts
2. **Output to stdout** - Like `jq`, pipe-friendly by default
3. **Simple interface** - Minimal commands and options
4. **Readable output** - Generated scripts humans can understand
5. **Zero magic** - No hidden complexity or enterprise features
