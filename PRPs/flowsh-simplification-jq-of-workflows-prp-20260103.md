# flowsh Simplification PRP - "The jq of Workflows"

**Date:** 2026-01-03  
**Project:** flowsh Radical Simplification  
**Goal:** Transform flowsh from complex multi-purpose tool into focused YAML-to-shell converter

## FEATURE: Simplify flowsh to Core Workflow Compilation

### Problem Statement

flowsh has grown into a complex system with 10,000+ lines of code, fancy TUI, performance monitoring, visualization engine, and multiple export formats. This complexity makes it hard to maintain, explain, and adopt. Users want a simple tool that converts YAML workflows to executable shell scripts reliably.

### Target State: "The jq of Workflows"

Create a focused tool that does ONE thing extremely well:

- Input: YAML workflow file
- Output: Clean, readable shell script (< 100 lines)
- Focus: Reliability, simplicity, debuggability

### Core Requirements

**1. Minimal CLI Interface**

```bash
flowsh compile workflow.yaml        # Generate shell script to stdout
flowsh validate workflow.yaml       # Check for errors only
```

**2. Clean Shell Output**

- Generated scripts < 100 lines for typical workflows
- Human-readable bash with clear comments
- Standard error handling (`set -euo pipefail`)
- No monitoring, metrics, or complex abstractions

**3. Essential Features Only**

- YAML parsing and validation
- Basic shell script generation
- Clear error messages with line numbers
- Support for core node types: start, end, code, agent, variable-assignment

**4. Remove Complex Systems**

- ❌ Fancy TUI with ASCII art and progress bars
- ❌ Performance monitoring and metrics
- ❌ React Flow visualization engine
- ❌ Template system complexity
- ❌ Multiple export formats (SVG, Mermaid, DOT)
- ❌ Health monitoring
- ❌ Advanced themes and styling

## EXAMPLES:

### Example 1: Simple 3-Node Workflow

```yaml
# input: hello-world.yaml
workflow:
  nodes:
    - id: start
      type: start
    - id: greet
      type: code
      command: echo "Hello {{greeting_target}}"
    - id: end
      type: end
  edges:
    - from: start
      to: greet
    - from: greet
      to: end
```

```bash
# output: hello-world.sh (clean 20-line script)
#!/bin/bash
set -euo pipefail

# Hello World Workflow
# Generated by flowsh

GREETING_TARGET=${GREETING_TARGET:-"World"}

echo "Starting workflow..."

# Node: greet
echo "Hello $GREETING_TARGET"

echo "Workflow completed successfully"
```

### Example 2: Error Handling

```bash
# Bad YAML input
❌ Error in workflow.yaml:5
   → Node 'greet' missing required field 'command'
   💡 Add: command: "echo Hello"

# Good validation
✅ workflow.yaml is valid (3 nodes, 2 edges)
```

### Example 3: Usage Pattern

```bash
# The jq-like simplicity we want
flowsh compile my-workflow.yaml > deploy.sh
chmod +x deploy.sh
./deploy.sh
```
